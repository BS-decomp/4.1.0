## Where the ground truth comes from

Unity 4.7 serialises a *compiled* shader as a single string: the complete
ShaderLab text — name, properties, subshaders, per-pass tags and render state —
with the GLES/GLES3 programs inlined as
`SubProgram "gles " { "!!GLES …" }`. That string survives in the APK:

```
$ python3 tools/extract_apk_shaders.py
unpacked 132 serialized files from com.rexetstudio.blockstrike-780.apk
extracted 71 shaders -> tools/shader-extract
  Unlit/Texture                   1697 bytes   1 passes   4 subprograms (sharedassets2.assets)
  MADFINGER/Transparent/GodRays   4088 bytes   1 passes   4 subprograms (sharedassets4.assets)
  ...
```

The extractor reads the serialized length prefix instead of guessing where the
text ends, and rejects anything that is not balanced ShaderLab. The result is
committed to `tools/shader-extract/` (1.3 MB) as the reference for every later
change.

## Verification

`tools/verify_shaders.py` compares each shader asset with its APK counterpart:

* declared shader name;
* the **full property list** — name, label, type and default (this is what
  materials serialise against);
* render state of the first pass — `Blend`, `ZWrite`, `Cull`, `ColorMask`,
  `Offset`, `ZTest`, `LightMode`.

It already caught two real mistakes while this was written: a missing
`Cull Off` detection bug and `WFX/Additive (Soft) Alpha8`, which is
`Blend OneMinusDstColor One` in the APK and had been written as `Blend One One`.

Documented, intentional deviations (the tool knows about them):

| Shader | Deviation | Why |
| --- | --- | --- |
| `ProBuilder/Unlit Solid Color`, `ProBuilder/UnlitVertexColor`, `Particles/Additive` | `AlphaTest Greater x` → `clip()` | fixed-function alpha test no longer exists; `clip()` is Unity's own replacement |
| `Mobile/VertexLit` | `SHADOWCASTER`/`SHADOWCOLLECTOR` passes → `Fallback "Legacy Shaders/VertexLit"` | `SHADOWCOLLECTOR` was removed after Unity 4 |
| `ProBuilder/Diffuse Vertex Color` | `Fallback "Diffuse"` → `Fallback "Legacy Shaders/Diffuse"` | the built-in was renamed in Unity 5 |
| surface-based shaders | passes generated by the surface compiler | the APK contains that compiler's output, not hand-written passes |

## Known limits

* `TODO: unverified` — none of this has been compiled by Unity in this
  environment (no editor here). Property names, defaults and render state are
  machine-checked against the APK; the program bodies are hand transcriptions
  of the GLES code and need one visual pass in the editor.
* `Mobile/VertexLit` keeps the original fixed-function syntax
  (`Material`/`SetTexture`). Unity 2021 still converts those, but if it ever
  stops, that file is the one to port to CG.
* The extract also contains 54 shaders that are either Unity built-ins or NGUI
  shaders already present in the project; they were left alone and are only
  used as reference.
