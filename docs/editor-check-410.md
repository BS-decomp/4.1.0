# Проверка в редакторе — Block Strike 4.1.0 (октябрь 2026)

Что делать после фикса «шоколадных карт» (см. [`lightmaps-410.md`](lightmaps-410.md),
секция «2026-10 fix»).

## 1. Обновись и открой проект

1. Забери изменения этой ветки (`git pull`).
2. Открой `client/` в Unity **2021.3.45f2** — версия теперь закреплена в
   `client/ProjectSettings/ProjectVersion.txt`, предупреждения о чужой версии
   быть не должно.
3. Дай редактору переимпортировать изменённые шейдеры — это происходит
   автоматически, руками ничего нажимать не нужно.

## 2. Что было сломано (коротко)

`_BSLightmap` / `_BSLightmapST` не были объявлены в `Properties` шейдеров
`Mobile/Unlit (Supports Lightmap)` и `Mobile/VertexLit`, а
`MaterialPropertyBlock` адресует только объявленные свойства. Поэтому
запечённый свет не доезжал до шейдера, и все карты рендерились сырой альбедой
— плоско, темно, «шоколадно». Свойства объявлены (`[HideInInspector]`), теперь
байндер доезжает.

## 3. Проверь одну карту

1. Открой любую карту, например `Assets/Levels/Maps/Others/Villa/Villa.unity`.
2. Меню `Tools > Block Strike > Diagnose lighting` — отчёт упадёт в консоль.
   В норме:
   - `lightmaps bound: 1`;
   - `renderers ... fed through a property block: > 0` (в edit mode счётчик
     `with a lightmap index` может быть 0 — Unity сбрасывает индексы вне play
     mode, доставка идёт через property block);
   - `binder: 1 texture(s), N renderer(s) recorded` с N > 0;
   - у шейдеров — `recovery lightmap property present`.
3. `Tools > Block Strike > Lighting: debug view (cycle)` — прошёлкай
   normal → albedo → lightmap → UV1. Режим «lightmap only» должен показать
   серо-белую запечёнку, а не чёрный экран.
4. `Tools > Block Strike > Playtest` — карта должна быть освещена как в
   оригинале (в play mode работают оба пути: и `LIGHTMAP_ON`, и блок).

## 4. Если всё ещё чёрное / плоское

Приложи к вопросу (или в issue):

1. полный вывод `Diagnose lighting` из консоли;
2. первые ~30 строк ошибок/предупреждений консоли после открытия карты;
3. имя сцены и скриншот.

Диагностика различает «нет текстуры», «нет UV1», «нет лайтмапа» и «шейдер не
семплит» — по её выводу причина видна сразу.

## Чего не делать

- Не удаляй объекты `BS Legacy Lightmaps` из сцен — это доставка запечённого
  света.
- Не пересохраняй сцены «на всякий случай» — пока идёт починка, диффы сцен
  должны оставаться пустыми (кроме апгрейда версий, который делает сам Unity).
- Occlusion-данные в сценах устарели после де-батчинга (см.
  [`export-status.md`](export-status.md)); их ребайк — отдельная задача,
  чёрные карты от них не зависят.
